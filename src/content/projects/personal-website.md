The site you are reading. It holds my blog posts, short notes and projects.

## What it does

- Turns Markdown files into a fast static site.
- Lets you filter posts, notes and projects by tag.
- Has a search page and an RSS feed.
- Makes a social preview image for every page.
- Comes in light and dark themes.

## Built with

- Astro
- TypeScript
- Plain CSS
- Satori for preview images
