A command-line search engine I built for a university course.

## What it does

- Builds a graph of URLs from a set of web pages.
- Ranks each page with PageRank.
- Stores the words from each page in a binary search tree.
- Takes search words as command-line arguments and prints the top 30 matching pages.

## Built with

- C
- Graphs, linked lists and binary search trees
