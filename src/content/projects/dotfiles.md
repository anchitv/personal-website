The config files for my Linux desktop from 2021 and 2022.

## What it does

- Sets up the i3 window manager, with scripts to change screen brightness.
- Adds a polybar status bar with battery, network, sound, memory, temperature and weather.
- Configures zsh and vim, with a base16 dark theme for vim.
- Includes an Xresources file for X11 settings.

## Built with

- Shell scripts
- i3, polybar, zsh and vim config files
